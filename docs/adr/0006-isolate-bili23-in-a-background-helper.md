# 在独立后台助手中运行 Bili23

Bili23 的解析、登录和下载代码依赖全局配置、Cookie、信号总线与任务数据库，不能当作无状态库直接塞进播放器进程。Offline Bili 因此将固定版本的上游源码保留在 `vendor/Bili23-Downloader`，仅对便携数据路径做一个小补丁，并通过无界面的后台助手调用。开发环境使用 Python 子进程；冻结后的 Windows ZIP 使用同目录的 `OfflineBiliHelper.exe`，以隐藏窗口启动并通过结构化 JSON 行通信。

这样做使网络异常、上游模块变化和登录状态不会破坏离线播放与历史记录，同时保留明确的 GPL 源码边界和可追踪的上游提交。冻结助手使用普通目录形式而非单文件自解压形式，避免运行时向 Windows 临时目录写入文件；代价是发布包中会有一份独立的后台运行库。
